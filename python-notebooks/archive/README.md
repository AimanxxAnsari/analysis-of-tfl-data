# Archive

Exploratory notebooks from the dissertation period. They are **not** used for any result in
the README or the dissertation and are kept for reference only.

Their saved outputs (plots and tables) were stripped to keep the repository small. The
original notebooks, with all outputs, are preserved at the git tag
[`dissertation-submitted`](../../../../tree/dissertation-submitted/python-notebooks).

| Notebook | What it explored |
|---|---|
| `draft-test*.ipynb`, `main-draft.ipynb` | Early network-building and plotting experiments |
| `tfl-2014-centrality-repulsion.ipynb` | Alternative (force-directed) layout for the 2014 network |
| `simple-centrality-measures.ipynb` | Toy graphs used for the centrality examples in the dissertation's literature review |
| `london-street-map.ipynb` | Plotting stations over London boundary shapefiles |
| `webscrapping-data.ipynb` | Scraping station coordinates from OpenStreetMap's wiki (not used) |
| `cartesian.csv` | Projected x/y positions of 2014 stations from an earlier layout experiment |
